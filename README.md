    #### Overall Project Description:
    This project serves as a currency converter tool and a travel wallet for people who travel a lot from country to country. It is designed to track the balance of a user as he or she deposits or withdraws money from the current balance. It also remains relevant for the user wherever he or she may be, thanks to the feature of quickly converting the current balance to a new currency. This project utilizes Frankfurter API by b569fec for the conversion of available currencies. For other python modules utilized in the creation of this project, kindly check requirements.txt.

    #### Detailed Project Features Description:
    **Home Page**
    Launching the project in the terminal window starts off with the home page, from which the user is able to select two options: create an account or open an existing account. If the user inputs [C] in the terminal window, they will create an account, and if the user inputs [O] in the terminal, they will open an existing account. The code for this under the main function.

    **Create Account**
    If the user decides to create an account, the following inputs will asked from them: username, password, currency, and balance. All of this information is stored in database.csv. The username and password must not be existing, otherwise an error will occur and the user will be redirected back to the home page. The currencies available will be shown in their three-lettered ISO 4217 code. The user simply needs to type the code of their chosen currency. Finally, the balance of the user must not contain any alphabets. Once the user has inputted all the needed information, the data is stored in the database.csv and the user is redirected back to home page where they can now open their existing account. The function create_account only handles the storing of data in the database.csv. It needs the username, password, currency, and balance as attributes, this is to make testing of the function simpler.

    **Open Account**
    The user can open any existing account, as long as they know their username and password. These two inputs will be asked for when accessing this feature of the project. If the username or password does not exist in the database.csv or there is a mismatch between the two, the user is redirected back into the home page with an error message explaining the issue. The function open_account only handles accessing the database.csv file in order to validate the existence of the account the user is trying to open. It needs the username and password as attributes, this is to make testing of the function simpler. After the open_account validates the username and password, an instance of the Balance Class will be created, inputting the username as the attribute to create the object. This is to utilize the __init__ method in the class to get the other details from the csv file and input it in the account_details function.

    **Account Details**
    After a user inputs their username and password in the open account feature, they will be redirected to the account details page. A message will be displayed greeting the user by their username with their current currency and balance at the time they accessed the account. The display of the details and options, exiting the account, depositing an amount, and withdrawing an amount is done within the account_details function. Within the account details page, the user has five options to choose on what to do next.
    1. The first is to EXIT their account, which is performed if the user passes in [E] in the command line. This will redirect the user back to the home page.
    2. The second is to DELETE their account, which is performed if the user passes in [D] in the command line. A message of confirmation will be sent to the user, confirming if they truly wish to delete their account. The deletion will push through if the user passes in [Y] in the command line. A separate function handles the deletion.
    3. The third is to DEPOSIT some amount into their balance, which is performed if the user passes in [A] in the command line. The program will ask for the amount to be deposited and will automatically update the balance of the user. The program will create an instance of the Balance Class utilizing the deposit and update method to deposit the amount and update it in the database.csv file. A message indicating the new balance will be displayed after the deposit.
    4. The fourth is to WITHDRAW some amount from their balance, which is performed if the user passes in [W] in the command line. The program will ask for the amount to be withdrawn and will automatically update the balance of the user. The progaram will create an instance of the Balance Class utilizing the withdraw and update method to withdraw the amount and update it in the database.csv file. If the the amount to be withdrawn is more than the current balance, an error message will be displayed to the user indicating the issue and the update method will not push through; otherwise, a message indicating the new balance will be displayed after the withdrawal.
    5. The fifth is to CHANGE the currency of the user, which is performed if the user passes in [C] in the command line. The program will show the list of available currencies in their respective three-lettered ISO 4217 code. The user simple needs to type the code of their new chosen currency and the conversion will begin. A separate function handles the conversion, and a message of the new currency and balance will be displayed for the user.

    **Delete Account**
    This is a separate function called delete_account that deletes the users account and returns a message of confirmation that the account of the user has been deleted. It needs the username as the only attribute for the delete_account function. It works by creating an instance of the Balance Class and calling in the delete_account method from the Class. The reason for this separate function is to test its functionality in a much more straightforward way in pytest.

    **Change Currency**
    This is a separate function called change_currency that changes the currency of the user and returns a message indicating the new currency and balance. It needs the username and new chosen currency as attributes for the change_currency function. It checks if the old currency is the same as the new currency and returns an error message if this is the case. Otherwise, it requests the needed information from frankfurter api and converts it into a json file. The old balance is then multiplied to the new currency's conversion rate to acquire the new balance. Prior to this, an instance of the Balance Class is then created to utilize the update method to update the currency and balance.

    **class Balance**
    This is a class intended to create instance objects to manipulate and gather data from a user's account.
    1.  **__init__** is a method that initializes the creation of the object. It needs the username as an attribute and utilizes that information to search into the database.csv file and search for the account based on the given username. It assigns all the information of the user from the database.csv file to the instance object.
    2. **deposit** is a method that serves to create the new balance after a deposit. It contains an error checking feature and requires the amount to be deposited as an attribute.
    3. **withdraw** is a method that serves to create the new balance after a withdrawal. It contains an error checking feature and requires the amount to be withdrawn as an attribute.
    4. **delete_account** is a method that serves to delete the user's account. It uses a three-step procedure in deleting the account. The first is to create a new list called new_data where it stores all the other accounts in the database.csv file except for the user's account. It accesses the database.csv file and uses a for loop to append all information that does not belong to the user's account to the new_data list. The second step is ito overwrite everything in csv, creating a blank csv file only containing the headers. Finally the third step is it appends all the data from new_data list to the empty database.csv file using a for loop and the writerow functionality, successfully deleting the account.
    5. **update** is a method that is intended to update the currency and balance of the user after a deposit, withdrawal, or a change of currency. It is similar to the delete_account method in which it follows a three-step procedure and uses a new_data list. It first updates the currency and balance by assigning row['currency'] to self.currency and row['balance'] to self.balance. It then overwrites everything leaving only the headers. Finally it appends all the information from the new_data list back into the database.csv file using a for loop and the writerow functionality.
